Everything before the release window, in one card: the host on `deno_core` with the `rt.*`
namespace and the eight-class exit taxonomy; real timers and a bounded `rt.fetch`; the module
loader brought inside the read fence; `jsrt supervise` as a real process boundary with bounded
JSONL reports; the stdlib wave — `rt.kv`, `rt.media`, `rt.serve` — and the million-scale evidence
(1M op calls, 1M requests through `rt.serve`, 1,000 cold starts, a one-hour soak). Then the
2026-11-16 security verification, where every defence gained a regression test that fails without
it, and the supervisor's output caps, secret redaction and terminal neutralisation that closed out
the release.
