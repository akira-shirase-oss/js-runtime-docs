The first release of jsrt, a purpose-built JavaScript host. V8 executes scripts through
`deno_core`; the Rust host owns deny-by-default capabilities, the lifecycle and honest error
classification — `jsrt run` and `jsrt supervise`, the `rt.*` namespace, the capability manifest,
`rt.fetch`, `rt.kv`, `rt.media`, `rt.serve`, the exit-code contract and the load matrix. There are
no published binaries: v1.0.0 is built from source.
